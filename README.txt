HOW TO FINISH YOUR BIRTHDAY WEBSITE

1. Open script.js. At the top, change "Her Name" and "Susan", then edit the photo captions, letter, wishes and final message in your own words.
2. PHOTOS: put 6 pictures in the images folder, named photo1.jpg ... photo6.jpg (or change the names in script.js).
3. SONG: put her birthday song in the music folder and name it birthday.mp3
3b. LAST PAGE: put the car picture in images as car.jpg. Optional: put a second song in music as final-song.mp3 (it plays when she blows out the candles). If these files are missing, the site still works.
4. Test: double-click index.html (or use VS Code "Live Server").
5. PUBLISH FREE: create a GitHub repo, upload all files (keep the folders), then Settings > Pages > Deploy from branch "main". Send the link on WhatsApp.

Tip: compress photos first (under 500 KB each) so it loads fast on mobile data.
